# playgoblin

The command line tool, report builder and MCP server for PlayGoblin, an open-source QA bot that plays your game and reports bugs.
See https://github.com/grloper/playgoblin for the Unity package, the Unreal plugin and the full documentation.

    pip install playgoblin
    playgoblin report PlayGoblinRuns/<run>
    playgoblin mcp
